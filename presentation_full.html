Доступ к API 2ГИС
В рамках СЗ УВА ЦА-26-ВН/1153 получен доступ к альтернативному решению — API 2ГИС.

Выявленная ситуация

  • SberGeoData и Matchbox признаны нецелевыми и удалены из пространства КАП.
  • В пространстве отсутствуют альтернативы для геокодирования.
  • Геоданные планируется выносить во внешний сегмент сети для обработки с помощью сторонних API в сети Интернет.

Риск

При выносе данных для обработки во внешний сегмент могут возникать риски кибербезопасности.

Задачи

На SberData:

  • Реализовать целевой клиентский путь и инструменты по работе с геоданными в ЛЗ КАП.
  • Обеспечить доступность SberGeoData и Matchbox на целевом решении DataLab PRO при миграции с ЛДЗ 3.0.

На ЦК по АГиГИС:

  • Проработать сценарии работы через AI-ассистента на естественном языке без прямого доступа к данным.

Доступность сервисов SberGeoData в ЛЗ КАП — 2/2

Получено предложение по использованию альтернативного решения — API 2ГИС. Проведено тестирование доступности в рамках RnD-спринта «Исследование сервисов геокодирования и потоковой обработки геоданных в контуре Банка».

1. Встреча

Проведена встреча с представителями SberData.

2. Доступ

Выставлена заявка на получение ключа к API 2ГИС.

3. Тестирование

Проверены сервисы в пространствах Omega, DataLab AI и DataLab PRO.

Результаты тестирования

API 2ГИС исправно работает в пространствах Omega и DataLab AI.

  • Геокодирование адресов
  • Классификация адресов
  • Расчёт маршрутов между объектами
  • Поиск по организациям

Выявленное отклонение

API 2ГИС не работает в пространстве (на платформе) DataLab PRO.

Совместно с ОРЦД выставлено требование на SberData по доработке платформы DataLab PRO для доступа к API 2ГИС.

Нормализатор адресов

Нормализатор построен на базе open-source Python-библиотеки DeepParse для парсинга адресов. Библиотека использует встроенную LLM-модель и поддерживает адресные форматы более чем 60 стран.

Что распознается

  • Область
  • Район
  • Город
  • Улица
  • Номер дома

Результаты сравнения

96%Точность распознавания адресов с DeepParse
85%Точность при использовании регулярных выражений
82%Точность геокодирования после DeepParse
70%Точность геокодирования после регулярных выражений
DeepParse повышает точность распознавания адресов на 11 п.п. и точность последующего геокодирования на 12 п.п. по сравнению с регулярными выражениями.

Прямой геокодер

Для прямого геокодирования адресов в пространстве КАП разработан собственный геокодер на основе адресов ФИАС — Федеральной информационной адресной системы. В ФИАС содержится более 36 млн актуальных адресов России.

Подготовка данных

Выгрузка и преобразование базы ФИАС для работы геокодера.

Очистка данных

Метод очистки с использованием регулярных выражений и библиотеки Pullenti.

Поиск и сопоставление

Сопоставление с базой геокодера с помощью библиотеки RapidFuzz.

Преимущества

  • Высокая скорость работы на больших объёмах данных
  • Исправление опечаток и различных вариантов написания
  • Простота интеграции в ETL-процессы

Ограничения

  • Отсутствие понимания семантики адреса: сравнение выполняется на уровне строк
  • Чувствительность к отсутствию ключевых компонентов адреса: города, улицы, номера дома
  • Зависимость точности от предварительной нормализации и полноты справочника адресов

Модульный ГИС-сервис

В ЦК по АГиГИС накоплено большое количество инструментов для работы с геоданными. Они находились в разных репозиториях, требовали установки разных библиотек и знаний по разворачиванию рабочего окружения. Поэтому создана единая точка доступа — модульный ГИС-сервис.

Один вход — все инструменты

Единая точка доступа ко всем инструментам геоанализа в одном месте: пользователю не нужно искать нужный инструмент.

Интегрируемость модулей

Модули сервиса могут использоваться в рамках других проектов и задач.

Логирование

Сбор статистики использования приложений для формирования списка доработок.

Адаптивность как основа

Сервис готов к будущим запланированным миграциям.

Модульный ГИС-сервис объединяет инструменты ЦК в едином пространстве и снижает порог входа для пользователей.
